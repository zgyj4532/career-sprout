# PRD：Career Pilot 校园版第一阶段 / WSL 本地基线

## 用户目标

在已有 Windows + WSL 环境中方便运行 Career Pilot；利用现有代码二次开发，不全栈重写。低年级学生需要简单易用的网页入口。最终课程产品要求师生注册、岗位需求、技能自评、可编辑简历、非纯文字模拟面试、荐才与批量下载；本阶段只建立可信的本地精简基线。

## 本阶段成功结果

在 WSL 的项目根目录，首次初始化后使用 `npm run dev:local` 启动前后端及本项目基础服务，从 Windows 浏览器访问 `http://localhost:5173`。页面仅暴露明确可用的核心入口，无支付/邮件/爬虫等意外任务；修改可验证、可回退、可继续开发。

## 范围

保留 React/Vite、Express、MongoDB、Redis；保留或修复简历 CRUD/编辑/导出、个人资料、粘贴 JD 的分析入口、普通语音面试及历史反馈；在现有组件之上简化中文首页。正式认证保留 Clerk，本地无凭据可使用受限制开发身份，但不得把它当注册功能完成。

## 工作包

W0 只读审计与 Trellis 接管 → W1 WSL 运行基线与副作用隔离 → W2 模块停用与有限清理 → W3 鉴权/AI 配置边界 → W4 中文简单入口 → W5 回归、证据与交接。

## 不在本阶段

校园岗位发布、师生/校友完整角色体系、技能自评新模块、教师推荐、企业时间匹配、批量下载、公开上线、十余真人使用、宣传视频、答辩材料；这些需求后续仍须落实。招聘爬虫、视频神情评分、编程题运行环境均不优先。
