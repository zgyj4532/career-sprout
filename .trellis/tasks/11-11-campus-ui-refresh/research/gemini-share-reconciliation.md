# 与 Gemini 分享方案的核对

来源：https://share.gemini.google/jh71WCaR3Jc6  
核对日期：2026-11-11。分享是一条从 2026-10-16 延续到发布的设计对话，前后方案并不一致。以对话后段、并与当前仓库一致的部分为准。

## 采纳

- 普通页背景：暖纸 `#f4efe6`、顶部暖白光晕、24px 微点阵。窄屏关掉点阵。不恢复已删除的风景 SVG。面试间保持 `#0b1220`。不要玻璃拟态。
- 首页四个入口恢复为带图标、说明和水印的卡片。现有 `campus.css` 已有 `.campus-portal-grid` 等样式；缺的是 `HomePage.jsx` 不再渲染 `Icon` 和 `copy`。
- 做简历：左编辑、右已保存列表。标题与目标岗位并排。示例动作离开主按钮组。不改字段和保存/导出逻辑。
- 了解自己、找个方向、练面试：采用分享后段的双栏卡片。侧栏 `100vh` + `sticky`，实色底，不用 `backdrop-filter`。
- 找个方向：0 条或总页数小于等于 1 时隐藏分页。分享后段样例 JSX 把禁用的上一页/下一页放在标题旁，与同文「铁律：隐藏」冲突，任务采用隐藏。
- 方向筛选胶囊：分享前文提过，后段 JSX 没有。没有真实方向字段时不做假筛选。

## 不采纳

- 品牌改成 EchoFolio，口号改成「大一不迷茫，平时多练兵」或「咱平时啊，在大学咱们就练起来」。分享后段 CSS 标题写的是「职芽 (CareerSprout)」。当前首页口号和四个入口文案保持现状。
- 把四个入口改名为「做简历 / 练面试 / 分析岗位 / 我的档案」，或把路由改成 `/job-analysis`、`/archive`。继续用 `/profile`、`/jd`、`/resume`、`/interview`、`/history`。
- 新装一套 React Bits，或新增外部字体和风景图。粒子、聚光灯若已在仓库里，只按现有组件复用。
- 分享样例里新写的营销句子（如「准备好进入房间了吗」）不替换现有文案。
