# 重构做简历工作台

## Goal

做简历从单列长表单改成左编辑、右已保存列表。字段仍是标题、目标岗位、正文；动作仍是保存、导出 PDF、使用示例。

## Requirements

1. `.resume-workspace`：左侧编辑卡，右侧约 300px 历史栏。窄于 860px 时单列，历史在编辑器下面。
2. 标题和目标岗位在桌面端并排。
3. 「使用示例」移到正文标签一侧，离开保存和导出，避免和主按钮平级误触。按钮文案仍用现有「使用示例」，不改成分享样例里的「填入示例内容」。
4. 保存、导出 PDF 放在编辑卡底部，固定宽度，不满宽。
5. 已保存简历进右侧列表，显示现有标题。当前正在编辑的一项使用 `.is-active`。列表超过视口时在栏内滚动。
6. 输入聚焦用现有深绿，不用浏览器默认蓝框。

## Acceptance Criteria

- [ ] 桌面端能同时看到编辑区和已保存列表。
- [ ] 保存、导出、示例和切换历史简历的结果与改版前一致。
- [ ] 保存失败时正文仍留在输入框里。
- [ ] 窄屏没有横向滚动。

## Out of scope

- 新增简历字段或 Markdown 工具栏。
- 改 PDF 导出实现。
