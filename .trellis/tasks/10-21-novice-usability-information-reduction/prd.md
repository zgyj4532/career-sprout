# 新手易用性与页面信息减负

## Goal
第一次使用、不读说明也能开始：有简历就导入，没有材料也能聊兴趣、经历和想法；资料整理、正式面试和反馈都能看懂下一步。减少重复内容和重复操作，不靠缩小文字或隐藏风险降低密度。

## Background and decisions
用户已批准建立本任务并完成以下产品选择，尚未审批最终方案实施：完整新手流程B；有效维度评分A；首次入口导入简历A；无材料可交流；交流资料一次确认后保存；首次交流不打分；编辑后的材料“保存并继续”。

保留10-20任务所有未提交成果。新服务器备案/部署阻塞3–5名新手试用与物理手机验收，本地开发仍可继续。预览曾启动并打开首页，随后退出；完整视觉基线未取得，原因未定，不声称验收通过。

证据索引：`research/local-flow-audit.md`（本地文件/行号）、`research/mature-patterns.md`（GOV.UK、Europass、WCAG）、`research/upstream-patterns.md`（实际上游anurag3407/career-pilot，固定SHA）、`research/runtime-baseline.md`、`research/acceptance-matrix.md`。外部实现不是安全保证。

## Requirements

### R1–R6 页面信息与保护
- R1：覆盖首页、档案、简历、岗位、面试准备/答题/反馈及历史的操作层级。
- R2：删除重复说明、合并重复摘要；可选工具按需展示。必须完成的内容不隐藏，不嵌套折叠，不缩小文字来挤内容。
- R3：当前状态有明确主动作，首次、返回、空态、加载、错误可区分；减少重复填写和往返。
- R4：未保存、识别疑点、保存目标、覆盖风险、删除确认、授权范围和恢复入口保持可见；隐私、事实依据、版本和权限保护不退步。
- R5：参考成熟案例和固定版本上游，记录可借鉴方法与不能照搬的风险；研究结论及出处保留在证据索引，不复制上游较弱的恢复或假观测指标。
- R6：保留职芽品牌、现有功能可达性和现有技术栈，不做全站重设计。

### R7–R9 正式面试
- R7：复用有效的已有材料/方向，跨页保留准备单；最近明确使用的有效选择优先，失效则提示重新选择；无已有选择时可带入最近保存的有效简历并展示名称供修改。题数/模式作为可选设置，不自动开始。
- R8：录音转写和打字共用一个回答编辑区，转写后可校对；不静默覆盖已有文字、不自动提交。录音失败可继续打字，重试不丢已有回答。
- R9：显式保存且服务器确认后才推进；末题“保存并查看反馈”。回答保存失败保留文字；结果未知先恢复进度，总评失败单独恢复，不重复提交已保存回答。

### R10 评分A
只按真实可用维度计算，按其原相对权重归一化。缺失不作0，真实0正常计入，全部缺失无总分。显示评分范围和覆盖，不直接混合比较不同范围。历史成绩保留并标旧规则，不猜旧0分来源，不批量重算。反馈优先具体建议，分数次之。

### R11–R13 首次入口与交流
- R11：主入口“导入简历”；替代入口采用“没简历也可以给我讲讲你感兴趣的事”。接受经历、课程设计、兴趣和自己的想法，不要求完整简历。回访优先继续已有进度。
- R12：想法仍是设想，正在做和做完不混淆；不把“想做”写成“做过”、不虚构成果或技能。允许原样表达，不先填整套档案。
- R13：不上传、不预填也能开始交流。根据已明确回答逐步了解是否在读大学、专业和兴趣，不预设身份、不重复问已知信息、不强迫回答；随时可结束。它与正式面试用途明确区分。

### R14–R15 交流结果与个人资料
- R14：仅提取用户明确表达的资料，未知保留未知，不依据口音/表达/兴趣猜身份、专业或能力。候选可对应来源回答。结束后一次简短可编辑摘要，提供“保存到个人资料”和“暂不保存”，不逐项打勾，仅冲突单独询问。不静默覆盖已有资料；失败保留修改，重复保存不重复添加。确认资料不等于生成简历或授权教师。
- R15：首次交流只总结内容、给具体表达建议，不打能力分，不评价专业/兴趣好坏，不混入正式面试分数统计。

### R16 保存并继续
用户编辑简历或岗位后用于下一步时，主操作“保存并继续”。保存成功才携带新版本进入目标页面；保存失败或冲突保留当前编辑，不静默用旧版本、不放弃修改。已保存但跳转失败可以继续跳转，不重复创建。此规则不替代R14的独立资料确认。

## Acceptance Criteria
- AC1 / R1–R6：记录桌面与390px同状态前后对比和删减清单；每页当前主动作明确，功能仍可找到，必要风险可见；键盘焦点不被固定栏遮挡，加载/失败不伪装空态。
- AC2 / R7：已有简历可直接准备练习；截图岗位取消/后退/刷新后准备单保留；不存在或已删除的材料不被静默使用。
- AC3 / R8–R9：只有一个可编辑回答框；录音取消、转写迟到、拒绝权限、断网、重复点击不覆盖或丢失文字；确认保存才推进，末题总评恢复不重复提交。
- AC4 / R10：覆盖真实0、部分/全部缺失与旧记录；报告/历史一致显示范围及规则，未测表达不扣分，不改写旧成绩。
- AC5 / R11–R13：零上传零预填可开始交流并随回答推进；经历/课程设计/想法能表达，未完成想法不变成已完成成果，未知身份/专业不编造。
- AC6 / R14：摘要可编辑；暂不保存不改个人资料；确认后刷新仍在，冲突保护、失败恢复、防重复与跨账号隔离有效。
- AC7 / R15：交流结果无能力分，历史标注用途，不计入面试成绩；没有回答则不捏造总结、资料或建议。
- AC8 / R16：编辑后继续使用刚保存版本；失败留在原页且文字完整，跳转重试不重复创建；保持私有岗位默认及授权边界。
- AC9 / 全部：外部阻塞项单列，不用模拟浏览器代替学生/真机验收；真实模型结果、受控故障分支和实际API持久化证据分开记录。
