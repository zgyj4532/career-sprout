# Profile illustrations and motion

Make the four Profile views inviting while keeping each task obvious. Add original SVGs for personal details (notebook), experiences (trail of milestones), skills (toolkit), and import (document tray). Reuse motifs in the navigation and active view heading without changing labels, routes, or editing/import behavior.

Use a brief localized accent animation on view entry, not continuous canvas particles. Disable it with reduced-motion preferences. Decorative SVGs are hidden from assistive technology and never intercept input. Use existing theme colors; no dependencies or external assets.

Acceptance: each view has a distinguishable illustration; at 320/390/1440 CSS px illustrations do not overflow, obscure controls, or push the main action unnecessarily down. Keyboard focus and navigation remain intact. Verify the actual browser surface and reduced-motion behavior before handing back the local preview.
