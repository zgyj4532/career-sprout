# 认证入口与关联诊断日志

## Goal

交付可理解的注册、登录和待验证页面，以及可以从页面故障编号追到前后端日志的诊断链。对应父任务 R4/R6、AC4/AC6。

## Confirmed Facts

当前校园路由没有认证页（`frontend/src/campus/CampusApp.jsx:40-50`），`main.jsx:37-47` 仍支持真实 Clerk，`campus/api.js:17-20` 依赖全局 Clerk session。现有本地身份不是注册。当前真实 Clerk 配置缺失；Resend 本轮明确为接入预留。

## Requirements

- 中文登录、注册、验证说明与退出入口；界面区分真实会话、本地开发体验和邮箱认证尚未启用。
- Resend 只承担邮件投递，不冒充身份提供商；预留服务端配置和显式不可用响应，不生成假的验证成功或登录会话。
- 登录回跳限制为站内路径；教师权限不可由注册表单/本地存储/可编辑档案赋予。
- 所有 API 请求关联 requestId；记录开始、结束、阶段、耗时与结构化错误。录音、ASR、AI、保存/导出记录安全元数据。
- 用户看到中文恢复动作，技术信息进入可复制诊断区；日志不得包含密钥、cookie、认证头、验证链接、原始音频或简历/口述全文。私密日志文件忽略入库、限制大小和保留期。

## Acceptance Criteria

- [ ] 直接访问认证页面得到真实表单和服务状态，不再进入关闭页；缺配置时不宣称邮件已发送。
- [ ] 未验证/未登录不获得正式身份；已有 owner UID、不跨账号、loopback 开发限制不回退。
- [ ] 浏览器发起的 API 失败在前端诊断、响应头/JSON、服务端阶段与完成日志中可关联；网络失败可区分尚未到达服务端。
- [ ] 使用合成敏感标记检查日志，标记及 token/password/Authorization 均不出现。

## Out of Scope

本轮不接管真实 DNS、邮箱域名或制造凭据，不实现用户未要求的完整自建密码/会话系统；真实发信与正式双账号验收需有效外部配置。

## Dependencies

仅在父任务最新规划获批准后启动。先冻结身份、错误与 requestId 契约，再供成长、语音和教师子任务使用。
