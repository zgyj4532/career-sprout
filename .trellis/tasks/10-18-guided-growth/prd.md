# 新生成长引导与校园岗位档案

## Goal

让大学生从“不知道做什么”走到有目标、有技能证据和明确下一步，优先照顾大一大二新手；大三大四可以使用已有资料直接进入练习，不设置年级限制。让师生校友可录入真实岗位需求。对应父任务 R1/R5、AC1/AC5。

## Confirmed Facts

首页只有四个平级入口（`pages.jsx:18-44`），岗位结果是 JSON（`pages.jsx:238-239`），档案只有逗号分隔技能（`pages.jsx:1079`）。当前校园 API 没有岗位发布或学生自评资源。

## Requirements

- 首页按真实档案/目标/简历/面试进度推荐一个下一步；允许跳过未知目标，不强填虚假经历。
- 档案包含年级、方向兴趣、课程/社团/项目经历、技能熟练程度与证据、可实习时间；缺失资料明确显示“待补充”。
- 师生校友可录入企业、岗位、需求正文、来源、时间要求，保存后可重读；发布者有编辑权，普通使用者不能改他人岗位。
- AI 将岗位正文整理成技能要求，显示来源与待确认字段；模型失败不丢弃人工输入，不产生伪分析。
- 用低门槛的“没接触/学过/做过/能独立完成”自评代替仅输入技能名；保持自评标签，不宣称客观测评。
- 展示已具备、需要补充、证据不足和下一步练习，不暴露裸 JSON；选中的岗位与学生材料可带入简历及面试。

## Acceptance Criteria

- [ ] 新学生无简历/无岗位时可从一次课程或社团经历开始，完成后得到明确下一步，示例只有显式选择后才进入表单。
- [ ] 高年级学生可直接选择已有档案、简历和岗位，不被强迫重走低年级引导；首页使用品牌子任务提供的主口号/彩蛋组件，交互遵循父设计而不重复实现。
- [ ] 创建与编辑岗位后重读一致，缺 AI 时人工保存可用，分析成功时展示中文技能卡片与来源。
- [ ] 自评和可用时间持久化，旧档案缺新字段仍可读取，不把缺失当零分或不合格。
- [ ] 学生 A 不能修改 B 的私密档案或岗位；对外岗位展示不暴露学生私密资料。
- [ ] 360/390/768/1440 视口可完成引导，键盘可达、焦点明确、错误后输入保留。

## Out of Scope

不启用招聘爬虫、不编造招聘机会，不把可选客观测评取代核心文档要求的自评。

## Dependencies

依赖身份与诊断子任务的契约；冻结岗位/档案字段后供语音简历与教师推荐使用。品牌使用父任务指定名称。
