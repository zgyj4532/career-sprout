# 重构找个方向页面布局

## Goal

岗位页顶部不再是两根满宽长条。截图解析和手工录入并排；岗位列表成为看板；没有岗位时显示空态，页数不足时不展示无效分页。

## Requirements

1. 去掉「从岗位截图整理」「录入一个岗位」这种 100% 宽胶囊。
2. `.direction-ingest-grid` 为左宽右窄。左卡是 `.screenshot-dropzone`：森林绿虚线，中间是图标和现有上传说明；若现有文案没有「Ctrl+V」，不新写一句营销文案，只把控件放进虚线区。底部 `.ingest-footer` 左为现有「找回截图导入记录」，右为现有读取按钮。
3. 右卡放现有手工录入，按钮不再是满宽长条。文案保持页面上已有的句子。
4. 「浏览岗位」不再用原生折叠三角当主标题。改为 `.jobs-board-section`：标题加数量。分享前文的方向筛选胶囊在后段样例里已去掉；没有方向字段时不要做「全部 / AI算法 / 前端」假筛选。
5. 岗位数为 0 时显示 `.jobs-empty-state`。引导只用现有动作，不新增「填入示例岗位」除非页面里已经有这个动作。
6. 总页数小于等于 1 时不渲染上一页 / 下一页。分享样例把禁用按钮放在标题旁，与同文「隐藏」冲突，采用隐藏。有多页时分页在列表底部右对齐。
7. 已有岗位时用双列卡片，只展示现有标题、来源和操作。不发明匹配度徽章。

## Acceptance Criteria

- [ ] 有截图和没截图时，上传区都不是满宽长条。
- [ ] 0 条岗位时看到空态卡，看不到上一页 / 下一页。
- [ ] 粘贴、选择文件、读取、找回记录、手工录入仍走原来的处理函数。
- [ ] 960px 以下改为单列。

## Out of scope

- 新的岗位筛选接口、方向胶囊和匹配度徽章。
- 改截图解析接口。
