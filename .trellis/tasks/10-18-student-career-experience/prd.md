# 职芽：面向低年级学生的职业成长体验与架构优化

## Goal

以 `E:/学习资料/sundries/AI赋能职业发展和面试指导产品.docx` 的八项基本功能和易用性原则为首要目标，在现有 React/Vite、Express、MongoDB、Redis 项目上，完成全体大学生可使用、优先照顾大一大二新手的“找方向—补技能—整理经历—做简历—练面试—授权荐才”闭环。大三、大四学生同样可直接使用已有资料进入求职练习，不设置年级准入限制。`phase1-kit` 是运行、安全与验证基线，其早期功能裁剪不替代本次产品目标。

## Requirements

- **R1 新手引导**：首页推荐一个真实下一步，贯通档案、岗位探索、技能自评、简历和面试；允许没有实习/项目/岗位目标，使用课程或社团经历起步。电脑与手机视口可操作，不要求读JSON或写Markdown。
- **R2 可信录音**：麦克风授权前解释用途，默认音频、摄像头自选；实际采集开始才提示正在录音，计时和停止可见；停止后转写、编辑确认再提交；失败、重录、取消、离开均有可靠状态和资源释放。
- **R3 简历生成与润色**：口述或粘贴真实经历，结合自评与目标生成可编辑草稿，原文/建议可比较；确认采纳才更新，不编造经历、技术能力或指标。保留保存、重读与整洁中文A4 PDF，通常一页、最多第二页上半页，超长不截断也不假称合规。
- **R4 认证初始化**：中文注册、登录、验证说明与退出入口，预留Resend邮箱验证；未配置/未接通不得假发信、假验证、假登录。保留已有正式会话与UID所有权；本地体验与正式注册分开，不擅自重写认证系统。
- **R5 核心校园流程**：师生校友人工录入岗位，AI分析需求，学生自评并明确能力差距；结合技能与可实习时间推荐学生，生成企业定向简历，教师批量下载供企业使用。教师权限来自可信服务端；学生可控制并撤回指定教师的材料授权；定向版本由学生确认后才可导出。
- **R6 可定位日志**：前后端统一requestId，覆盖关键操作阶段、请求开始/结束、耗时与异常；页面给中文恢复动作和可复制诊断信息。提供受限、忽略入库的日志存储；不记录密钥、认证信息、验证链接、原始音频或个人材料全文。
- **R7 品牌迁移与口号彩蛋**：中文“职芽”，英文“CareerSprout”，主口号“从现在开始，让每一次练习长成未来。”；首页点击主口号，以 React Bits 文字动画切换为“咱平时啊，在学校咱们就练起来”，再次点击恢复，默认不自动轮播。统一当前产品、文档与包名称，本地目录改为 `E:/github/career-sprout`，优先将用户fork改为 `zgyj4532/career-sprout`；确认无法改名时，按用户要求采用备份原Git历史后重新初始化并新建仓库的备选路径，不删除唯一历史副本或GitHub旧仓库。保留上游署名、用户修改及持久数据标识。
- **R8 实际验证与交付**：实际启动和操作受影响流程，记录浏览器、接口、PDF和针对性质量结果，交付启动、配置、日志及排障说明。真实服务、正式账号和真人/真机条件分项验证，不以测试替身冒充完成。
